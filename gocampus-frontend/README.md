# CampusEvents — React + Vite

Экспорт Figma Make, адаптированный для самостоятельного запуска на Windows / VS Code.

## Запуск

1. Установите Node.js 22 или новее.
2. Откройте папку проекта в VS Code.
3. В терминале запустите:

```bash
npm install
npm run dev
```

4. Откройте ссылку, которую покажет Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

Исходные страницы находятся в `src/routes.tsx`, оформление в `src/index.css`.

**Важно:** данные мероприятий в проекте демонстрационные. Для настоящей авторизации, хранения регистраций и синхронизации с сервером нужен backend. Часть изображений загружается по внешним URL и требует подключения к интернету.
